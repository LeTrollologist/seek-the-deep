## What this project is

Seek the Deep is a local browser extension for exporting the signed-in user’s **own** DeepSeek conversations. It has no server, no analytics, and no third-party upload. It reads the active conversation through DeepSeek’s web interface using the browser session already present in the user’s tab. It is **not built on a documented public API**, and DeepSeek may change or restrict that interface at any time.

## Intended use

- Export your own conversations for personal backup, research, accessibility, or portability.
- Export one conversation at a time, initiated by you.
